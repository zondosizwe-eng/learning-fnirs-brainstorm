# How to use this course

Each lesson identifies:

- the **input file** selected in the Brainstorm database tree;
- the exact **GUI route** and important parameters;
- the expected **output derivative**;
- the scientific reason for the step;
- a checkpoint and short self-assessment.

## Before you begin

You should have:

- a working Brainstorm installation with the NIRSTORM processes available;
- the tutorial dataset extracted to a known folder;
- permission to write to the Brainstorm database folder;
- enough disk space for imported anatomy, derived files and figures;
- completed each preceding lesson, unless the page explicitly states otherwise.

Work through the lessons in order. Later pages refer to derivatives created earlier, and similarly named files can belong to different signal domains.

## Teaching conventions

!!! warning "Do not work from filenames alone"
    Before running a process, confirm the file's data domain: raw intensity, dOD, motion-corrected dOD, haemoglobin, filtered haemoglobin or an epoch average.

!!! note "Screenshots"
    Screenshots come from the 2026 Brainstorm interface. Older or newer versions may use slightly different menu wording. Read each caption and use the surrounding database-tree context to confirm that you have selected the same type of input.

!!! tip "Use the images actively"
    Enlarge a screenshot when a label is difficult to read, then compare the highlighted panel, menu or output with your own Brainstorm window before continuing.

## Anatomy for studies without participant MRI

The tutorial dataset includes individual anatomy. In portable NIRSport2 studies without participant MRI scans, select the protocol's default anatomy and register the nominal montage to a standard template. Report localisation as a **template-based estimate**, not participant-specific anatomy.

## Quiz rule

Lessons 1–16 end with five multiple-choice questions. Attempt each question before opening its answer panel. Lessons 17–18 are planning pages and will receive their full activities and quizzes only after the five-participant analysis is completed.
