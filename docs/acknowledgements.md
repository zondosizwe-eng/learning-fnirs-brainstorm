# Acknowledgements and key publications

## Relationship to the original tutorial

This course is an expanded, screenshot-led teaching guide based on the official **NIRSTORM: a Brainstorm extension dedicated to functional Near Infrared Spectroscopy (fNIRS) data analysis, advanced 3D reconstructions, and optimal probe design** tutorial by **Édouard Delaire and Christophe Grova**.

The original tutorial remains the authoritative source for the NIRSTORM workflow, software-specific guidance and tutorial dataset:

- [Official Brainstorm/NIRSTORM tutorial](https://neuroimage.usc.edu/brainstorm/Tutorials/NIRSTORM)

This student guide reorganises the workflow into shorter lessons, adds screenshots captured during the learning process, explains the file lineage and provides checkpoints, troubleshooting notes and self-assessment questions. It is an independent educational adaptation and is not official Brainstorm or NIRSTORM documentation.

## Primary NIRSTORM publication

The official tutorial asks users of NIRSTORM to cite the following article:

> Delaire, É., Vincent, T., Cai, Z., Machado, A., Hugueville, L., Schwartz, D., Tadel, F., Cassani, R., Bherer, L., Lina, J.-M., Pélégrini-Issac, M., & Grova, C. (2025). NIRSTORM: A Brainstorm extension dedicated to functional near-infrared spectroscopy data analysis, advanced 3D reconstructions, and optimal probe design. *Neurophotonics, 12*(2), 025011. [https://doi.org/10.1117/1.NPh.12.2.025011](https://doi.org/10.1117/1.NPh.12.2.025011)

- [Open-access full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC12081164/)

This is the principal software paper for the Brainstorm extension used throughout Lessons 1–16.

## Finger-tapping optical-tomography workflow

The official tutorial identifies the following article as the detailed scientific description of the personalised finger-tapping acquisition and three-dimensional optical-tomography workflow:

> Cai, Z., Uji, M., Aydin, Ü., Pellegrino, G., Spilkin, A., Delaire, É., Abdallah, C., Lina, J.-M., & Grova, C. (2021). Evaluation of a personalized functional near infra-red optical tomography workflow using maximum entropy on the mean. *Human Brain Mapping, 42*(15), 4823–4843. [https://doi.org/10.1002/hbm.25566](https://doi.org/10.1002/hbm.25566)

- [Open-access full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC8449120/)

This article provides the research context for the personalised montage, finger-tapping experiment, anatomical modelling and cortical reconstruction demonstrated in the tutorial.

> Tadel, F., Baillet, S., Mosher, J. C., Pantazis, D., & Leahy, R. M. (2011). Brainstorm: A user-friendly application for MEG/EEG analysis. *Computational Intelligence and Neuroscience, 2011*, 879716. [https://doi.org/10.1155/2011/879716](https://doi.org/10.1155/2011/879716)

## Dataset-use note

The official NIRSTORM tutorial states that its fNIRS and MRI tutorial dataset remains proprietary to the MultiFunkIm Laboratory and restricts use or transfer outside the Brainstorm tutorial without written consent. This course therefore links students to the official tutorial rather than redistributing the raw dataset.

Before publishing data-derived screenshots beyond the intended teaching context, the course author should confirm that the planned use is consistent with the tutorial conditions or obtain clarification from the tutorial authors.
