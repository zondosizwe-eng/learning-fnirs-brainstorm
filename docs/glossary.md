# Glossary

| Term | Meaning in this course |
|---|---|
| **Brainstorm** | The host neuroimaging GUI and database environment. |
| **NIRSTORM** | Brainstorm extension adding fNIRS-specific processing and reconstruction. |
| **SNIRF** | Standard file format for fNIRS recordings and metadata. |
| **Source** | Optode that emits near-infrared light into the head. |
| **Detector** | Optode that measures light returning from the head. |
| **Source–detector pair** | A measurement channel formed by one source and one detector. |
| **NAS / LPA / RPA** | Nasion, left preauricular and right preauricular fiducials used for spatial registration. |
| **Coregistration** | Alignment of the optode geometry and anatomical model in a common coordinate system. |
| **dOD / ΔOD** | Change in optical density relative to a reference level. |
| **TDDR** | Temporal derivative distribution repair for motion-related changes. |
| **MBLL** | Modified Beer–Lambert law used to estimate haemoglobin changes. |
| **HbO** | Oxygenated haemoglobin concentration change. |
| **HbR** | Deoxygenated haemoglobin concentration change. |
| **HbT** | Total haemoglobin estimate, commonly HbO + HbR. |
| **SCI** | Scalp coupling index, commonly based on wavelength agreement in the cardiac band. |
| **CV** | Coefficient of variation; a relative variability measure used in signal-quality assessment. |
| **IIR filter** | Infinite impulse response filter; the filter family used in the temporal-cleaning lesson. |
| **Epoch** | A time segment aligned to a repeated event. |
| **Baseline correction** | Subtracting a reference-period level from an epoch to express change relative to baseline. |
| **Scout** | Brainstorm region of interest on a surface. |
| **Fluence** | Modelled light energy distribution through tissue. |
| **Sensitivity map** | Spatial sensitivity of a measurement to absorption changes. |
| **wMNE** | Weighted minimum-norm estimate used here for cortical reconstruction. |
| **ROI** | Region of interest used to define an anatomical or functional summary area. |
| **GLM** | General linear model; a framework for estimating task-related effects from a specified design. |
